# Окна переменных

## Окно выбора грузового тельфера

Переменные для ввода пользователем:

* тип тельфера (hoist type) - список:
  * канатный;
  * цепной;
  * любой;
* количество колёс ($n_{wheels\_{hoist}}$) - список:
  * 4;
  * 8;
  * любое;
* тип строительной высоты (headroom type) - список:
  * нормальная строительная высота;
  * уменьшенная строительная высота;
  * любая;
* производитель тельфера (hoist manufacturer) - список  (по умолчанию должен быть выбран "NANTE"):
  * список представленных в базе данных производителей тельферов;
  * любой.
