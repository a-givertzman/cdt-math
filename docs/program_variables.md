# Окна переменных

## Окно выбора грузового тельфера

Поля для выбора пользователем:

* тип тельфера (hoist type) - список:
  * канатный;
  * цепной;
  * любой;
* количество колёс ($n_{wheels\_{hoist}}$) - список:
  * 4;
  * 8;
  * любое;
* тип строительной высоты (headroom type) - список:
  * нормальная строительная высота;
  * уменьшенная строительная высота;
  * любая;
* производитель тельфера (hoist manufacturer) - список  (по умолчанию должен быть выбран "NANTE"):
  * список представленных в базе данных производителей тельферов;
  * любой.

## Окно выбора пролётной балки

Поля для выбора пользователем отсутствуют.

## Окно концевой балки

Поля для выбора пользователем:

* тип подкранового пути - строка:
  * либо подкрановый путь из исходных данных (нельзя выбрать другой, возможно при наведении курсора выдавать сообщение "Можно изменить в окне инициализации" или подобное);
  * либо выбор одного значения из списка доступных подкрановых путей (из [каталога](/docs/catalogsPurchasedEquipment.xlsx) или отдельного списка путей)

## Окно выбора привода передвижения

Поля для выбора пользователем (ориентировочно):

* производитель привода (мотор-редуктора механизма передвижения крана):
  * BONENG;
  * SEW-EURODRIVE.
