# Выбор пролётной балки крана

## Цель

Выбрать подходящий тип и сечение пролётной балки
___

В данный момент выбор сечения пролётной балки делаем по составленном каталоге готовых решений
Для однобалочных опорных кранов в качестве механизма подъёма выбираем только передвижные подвесные тельферы с электрическим типом привода.

### Условия выбора

Выбор сечения пролётной балки производится по каталогу готовых решений при выборе по нескольким условиям:

* грузоподъёмность крана:
$$M_{load\ specification} \leq M_{load\ catalog},$$
где $M_{load\ specification}$ - грузоподъёмность крана по ТЗ;  
$M_{load\ catalog}$ - грузоподъёмность крана в каталоге готовых решений;
* пролёт (длина пролёта):
$$L_{span\ specification} \leq L_{span\ catalog},$$
где $L_{span\ specification}$ - длина пролёта (пролёт) крана по ТЗ;  
$L_{span\ catalog}$ - длина пролёта (пролёт) крана в каталоге готовых решений;
* высота подъёма:
$$H_{lifting\ specification} \leq H_{lifting\ catalog},$$
где $H_{span\ specification}$ - высота подъёма крана по ТЗ;  
$H_{span\ catalog}$ - высота подъёма крана в каталоге готовых решений.
