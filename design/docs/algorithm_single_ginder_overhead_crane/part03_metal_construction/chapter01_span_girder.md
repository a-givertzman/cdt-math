# Выбор пролётной балки крана

## Цель

Выбрать подходящий тип и сечение пролётной балки
___

В данный момент выбор сечения пролётной балки делаем по составленном каталоге готовых решений.
Тип ездовой полки пролётной балки может быть двух видов:

* полка с уклоном внутренних граней;
* с параллельными гранями полок.

### Условия выбора

Выбор сечения пролётной балки производится по каталогу готовых решений при выборе по нескольким условиям:

* грузоподъёмность крана:
$$M_{load\ specification} \leq M_{load\ catalog},$$
где $M_{load\ specification}$ - грузоподъёмность крана по ТЗ;  
$M_{load\ catalog}$ - грузоподъёмность крана в каталоге готовых решений;
* пролёт (длина пролёта):
$$L_{span\ specification} \leq L_{span\ catalog},$$
где $L_{span\ specification}$ - длина пролёта (пролёт) крана по ТЗ;  
$L_{span\ catalog}$ - длина пролёта (пролёт) крана в каталоге готовых решений;
* высота подъёма:
$$H_{lifting\ specification} \leq H_{lifting\ catalog},$$
где $H_{span\ specification}$ - высота подъёма крана по ТЗ;  
$H_{span\ catalog}$ - высота подъёма крана в каталоге готовых решений;
* тип ездовой полки:
  * если выбрана грузовая таль под полку с параллельными гранями, выбираем сечение в каталоге по столбцу для параллельной полки;
  * если выбрана грузовая таль под полку с уклоном внутренних граней, проверяем и подбираем сечение в каталоге по столбцу "наклонная полка", однако если при прочих подходящих условиях данных о сечении в этом столбце нет, выбираем соответствующее сечение в каталоге из столбца для параллельной полки.

### Виды сечения пролётной балки

Сечение пролётной балки может быть нескольких видов:

* цельная двутавровая балка (*Наименование* и *ГОСТ двутавра*);
* цельная двутавровая балка с приваренной полосой усиления нижнего пояса (*Наименование* и *ГОСТ двутавра* + *Ширина полосы* х *Толщина полосы*);
* сварная коробчатая балка (*Высота стенки*\_*Ширина нижнего пояса*\_*Ширина верхнего пояса*\_*Толщина стенки*\_*Толщина нижнего пояса*\_*Толщина верхнего пояса*).
